# 隐私与公开发布范围

## 这个源码包包含什么

应用后端、网页资源、通用协作提示词、离线回归测试、启动/依赖准备脚本和公开说明。演示截图使用合成任务，测试使用临时目录及虚构数据。

源码包不包含原始项目的业务文档、车辆数据、会话数据库、上传附件、日志、历史导出、截图证据、账号配置、SSH 私钥或已安装 CLI。公开仓库从新历史开始，未导入原工程历史。

## 使用时的数据流

```text
你的浏览器 → 本机 Python 服务 → 已登录的本机 CLI → 对应模型服务商
                   ↓
              data/ 本地数据
```

选择发送的文本、上下文、附件片段或图片会通过 CLI 提交给所选服务商。网页代码不等于离线模型；使用前请确认各自服务商的数据政策和账号设置。

## 本机保存内容

| 位置 | 内容 |
| --- | --- |
| `data/collaboration.sqlite3` | 对话、任务、设置、事件与问答 |
| `data/uploads/` | 用户上传与引用元数据 |
| `data/context-archives/` | 摘要前原文 |
| `data/archive/` | 每日记录和交接导出 |
| `data/agent-workspace/` | 默认代理工作目录 |
| `config.local.json` / `runtime-manifest.json` | 本机运行路径 |

浏览器存储还可能包含草稿、主题与阅读状态。退出或刷新不会自动清理这些内容。用户指定外部工作/资料目录后，读写可能发生在所选目录中。

应用的秘密遮盖及受保护文件检查只是辅助，不能识别所有个人资料。完全访问会使用本机权限及已有连接，资源协调不能替代操作系统隔离。

## 提交前检查

1. 运行 `python scripts/privacy_check.py`，再检查 `git diff --cached` 和 `git ls-files`。
2. 不提交 `data/`、本地配置、数据库、原始日志、凭据、真实聊天或外部客户资料。
3. 截图只使用合成数据，检查可见用户名、路径、地址、额度和任务内容。
4. 若凭据曾经公开，应及时撤销或轮换；只删除最新文件无法清除已公开历史。

自动扫描只能检查已知形式，不能证明没有任何隐私。默认不上传遥测；使用的外部 CLI 可能有其自身网络和遥测行为，请按官方设置管理。
