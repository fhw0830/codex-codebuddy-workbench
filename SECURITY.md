# Security policy

CodeDuo is a personal local application. It binds to loopback and has no multi-user authentication. Do not expose it to untrusted users or networks.

For a security issue, use GitHub's private vulnerability reporting when the repository exposes that option. If unavailable, create an issue asking for a private reporting channel without including exploit details or confidential data. Never attach credentials, private conversations or live runtime databases to public issues.

Please include the affected release, a synthetic reproduction, expected access boundary and observed behavior. There is no guaranteed response-time SLA. Keep external agent CLIs updated deliberately and verify protocol compatibility after changes.
